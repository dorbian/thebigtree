What Pass A owns

Every game snapshots server identity policy, owns a generic rooms registry, and records a per-game relay webhook ID without storing the webhook token. Living Circle and Lost Forest remain compatibility fields while also registering as ordinary managed rooms.

Moderator identity resolution is deliberately separate from game-host controls, requires admin:web, excludes secret roles, and writes an audit entry to the server log.
